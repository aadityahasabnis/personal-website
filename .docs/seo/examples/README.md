# SEO Examples

This folder contains copy-ready examples built from the main SEO playbook.

## Files

1. `article-seo-og-schema-template.md`

- Reusable article metadata template
- Covers SEO metadata, Open Graph, Twitter cards, and Article JSON-LD
- Includes a publish checklist and validation workflow

## How to Use

1. Copy the article template into your content workflow notes for a new post.
2. Replace all placeholder values (title, slug, dates, image, description).
3. Validate before publish using Search Console, Rich Results Test, and social debuggers.
4. Keep values consistent across canonical, OG URL, and schema `mainEntityOfPage`.
